## تفعيل الـGuestbook

الـGuestbook بيحفظ الرسائل ويعرضها لكل زوار الموقع. عشان كده محتاج قاعدة بيانات Supabase بسيطة جنب GitHub Pages. المشروع الحالي متوصل بالفعل. لو هتستخدمي مشروع Supabase تاني، شغّلي `guestbook-setup.sql` وبعدها حدّثي `supabaseUrl` و`supabasePublishableKey` في أول `script.js`.

1. اعملي مشروع جديد على Supabase.
2. افتحي **SQL Editor** في مشروعك، وانسخي محتوى الملف `guestbook-setup.sql` وشغّليه.
3. من إعدادات المشروع، انسخي **Project URL** و**Publishable key**.
4. افتحي `script.js` وحدّثي القيمتين دول في أول الملف:

   ```js
   supabaseUrl: "",
   supabasePublishableKey: ""
   ```

5. احفظي التعديلات وانشري الملفات على GitHub Pages. بعد التوصيل، أي رسالة جديدة هتظهر على الموقع لكل الزوار.

استخدمي **Publishable key** بس في الموقع. ما تحطيش `service_role` أو أي Secret key في ملفات الموقع. سياسات قاعدة البيانات في ملف SQL بتسمح للزوار يقروا الرسائل وينشروا رسالة، ومش بتسمحلهم يعدلوا أو يمسحوا رسائل.

## استقبال ردود الدعوة

الموقع بيحفظ رد الضيف مباشرةً في Supabase بدل ما يفتح تطبيق الإيميل عنده. لتجهيز جدول الردود على مشروع جديد، شغّلي `rsvp-setup.sql` مرة واحدة من **SQL Editor**. الردود بتظهر للعروسين فقط من **Table Editor → wedding_rsvps**؛ الزوار يقدروا يضيفوا رد، لكن ما يقدروش يقروا ردود غيرهم. الموقع ما بيبعتش إشعار إيميل تلقائيًا.

## نشر الموقع مجانًا على GitHub Pages

1. اعملي مستودع **Public** جديد على GitHub؛ النشر على GitHub Pages متاح مجانًا للمستودعات العامة.
2. ارفعي محتويات المجلد ده مباشرة في أول المستودع. لازم `index.html` يبقى في المستوى الرئيسي جنب `styles.css` و`script.js`.
3. من المستودع افتحي **Settings → Pages**.
4. تحت **Build and deployment** اختاري **Deploy from a branch**.
5. اختاري فرع `main` ومجلد `/(root)`، وبعدها **Save**.
6. بعد ما النشر يخلص، هتلاقي رابط الموقع في صفحة **Settings → Pages**، وغالبًا هيبقى بالشكل ده: `https://اسم-حسابك.github.io/اسم-المستودع/`.

أي تعديل ترفعيه بعد كده على الفرع المختار هيتنشر تلقائيًا. [شرح GitHub الرسمي للنشر من فرع](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## تعديل باقي البيانات

الإعدادات الأساسية كلها موجودة في أول ملف `script.js`:

- `rsvpDeadline`: آخر ميعاد للرد.
- `musicSrc`: مسار ملف موسيقى معاكي حق استخدامه، زي `assets/music.mp3` بعد ما تضيفي الملف للمجلد.
- `supabaseUrl` و`supabasePublishableKey`: لتوصيل الـGuestbook وحفظ ردود الدعوة.

لو عايزة تعايني الموقع على جهازك، افتحي `index.html` في متصفح حديث. الخريطة والـGuestbook وردود الدعوة محتاجين إنترنت، وGuestbook/RSVP محتاجين إعداد Supabase.
